# الموقع المطوّر — أحمد حسين عبد الله سيد

نسخة تفاعلية ثنائية اللغة مع قاعدة بيانات أونلاين عبر Supabase، لوحة إدارة، إدارة أعمال ومنتجات، وطلبات عملاء مع فتح رسالة واتساب جاهزة لصاحب الموقع.

## محتويات المشروع
- `index.html`: واجهة الموقع ونموذج الطلب ولوحة الإدارة.
- `style.css`: التصميم المتجاوب والوضع الداكن.
- `app.js`: الاتصال بقاعدة البيانات وإدارة المحتوى والطلبات.
- `config.js`: إعدادات مشروع Supabase ورقم واتساب.
- `supabase/schema.sql`: إنشاء الجداول وسياسات الأمان ومساحة الصور.
- `assets/`: ضع صورة صاحب الموقع باسم `profile.jpg`.

## 1) إعداد Supabase
1. أنشئ مشروعًا في https://supabase.com/.
2. افتح SQL Editor ونفّذ محتوى `supabase/schema.sql` كاملًا.
3. من Project Settings > API انسخ Project URL وPublishable/anon public key.
4. ضع القيم في `config.js` بدل:
   - `https://YOUR-PROJECT.supabase.co`
   - `YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY`
5. لا تضع `service_role` أو أي مفتاح سري في ملفات الموقع المنشورة.

## 2) إنشاء حساب المسؤول
1. من Supabase > Authentication > Users أنشئ مستخدمًا بالبريد وكلمة المرور الخاصة بك.
2. انسخ UUID لهذا المستخدم.
3. في SQL Editor نفّذ:
   ```sql
   insert into public.admins(user_id)
   values ('ضع-UUID-حساب-المسؤول-هنا');
   ```
4. رابط "دخول الإدارة" موجود أسفل الموقع. سجّل الدخول بالبريد وكلمة المرور. حسابات المستخدمين العادية لا تصبح مسؤولة إلا إذا أضفت UUID الخاص بها يدويًا إلى جدول `admins`.

## 3) رقم واتساب
`config.js` مضبوط مبدئيًا على رقم الهاتف الذي زودتنا به: `201206988818`.
رقم واتساب يجب أن يكون مفعّلًا على نفس الرقم. إذا كان رقم واتساب مختلفًا، غيّر `WHATSAPP_NUMBER` إلى الصيغة الدولية دون + أو مسافات.

عند إرسال العميل طلبًا:
- يُحفظ الطلب في جدول `orders`.
- تُفتح نافذة واتساب برسالة جاهزة تحتوي المنتج واسم العميل ورقمه والكمية والملاحظات ورقم الطلب.
- على العميل/المتصفح تأكيد إرسال الرسالة من واتساب؛ فتح الرابط لا يعني أن الرسالة أُرسلت تلقائيًا.
- تظهر الطلبات في لوحة الإدارة.

## 4) إضافة الأعمال والمنتجات
من أسفل الموقع افتح "دخول الإدارة" وسجّل الدخول:
- إدارة الأعمال: أضف عنوان العمل والوصف والصورة.
- إدارة المنتجات: أضف الاسم والوصف والسعر والتوفر والصورة.
- طلبات العملاء: تابع الطلبات وغيّر الحالة إلى جديد/قيد التنفيذ/مكتمل/ملغي.

الصور تحفظ في Supabase Storage داخل bucket اسمه `portfolio-media`. الحد الأقصى 5MB والصيغ المقبولة JPG وPNG وWebP.

## 5) النشر على GitHub Pages
1. ارفع جميع محتويات المجلد إلى جذر مستودع GitHub.
2. تأكد من تعديل `config.js` قبل النشر.
3. من Settings > Pages اختر Deploy from a branch ثم `main` و`/(root)`.
4. بعد اكتمال النشر استخدم رابط HTTPS الذي يعرضه GitHub Pages.

## ملاحظات أمان وتشغيل
- المفتاح الموجود في الواجهة يجب أن يكون Publishable/anon فقط، مع تفعيل سياسات RLS في SQL.
- لا تستخدم service_role في المتصفح إطلاقًا.
- صلاحية الإدارة تعتمد على وجود المستخدم في جدول `admins`، وليس على إخفاء زر الإدارة.
- إدخال الطلبات العامة مسموح، لكن قراءة الطلبات وتعديلها محصوران في المسؤول.
- إشعار واتساب هنا يتم عبر رابط `wa.me` يفتحه المتصفح؛ لا يرسل رسالة تلقائيًا في الخلفية. للإرسال الآلي الحقيقي يلزم WhatsApp Business Platform وخادم وسيط آمن.
- صور المشروع الأصلية لم تكن متاحة في طلب التطوير؛ أضف الصور التي تملكها فقط.
